# Frontmatter Studio

A RTL-friendly frontmatter editor for Markdown files in Visual Studio Code.

## Features

* Edit Markdown frontmatter with a dedicated interface
* RTL-friendly editing experience
* Validate YAML frontmatter
* Designed for a clean Markdown workflow
