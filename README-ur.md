# Frontmatter Studio

**Visual Studio Code کے لیے Markdown فائلوں کے Frontmatter میں ترمیم کرنے کا آسان اور بصری طریقہ۔**

Frontmatter Studio آپ کو Markdown فائلوں کے Frontmatter کو YAML کوڈ میں براہِ راست ترمیم کیے بغیر ایک سادہ اور آسان بصری ایڈیٹر کے ذریعے بنانے، تبدیل کرنے اور جانچنے کی سہولت فراہم کرتا ہے۔

یہ توسیع **Generalsoft FZ-LLC** نے تیار کی ہے۔

## ✨ اہم خصوصیات

### بصری Frontmatter ایڈیٹر

Markdown فائل کے Frontmatter کو براہِ راست YAML میں تبدیل کرنے کے بجائے ایک آسان بصری ایڈیٹر کے ذریعے ترمیم کریں۔

یہ ایڈیٹر درج ذیل معلومات کو تبدیل کرنے کی سہولت فراہم کرتا ہے:

* عنوان
* تفصیل
* مصنف
* تاریخ
* تھمب نیل
* ٹیگز

### 📅 تاریخ منتخب کرنے کی سہولت

تاریخ درج کرنے کے بجائے کیلنڈر کے ذریعے تاریخ منتخب کریں۔

Frontmatter Studio تاریخ کو درست انداز میں پڑھتا اور محفوظ کرتا ہے تاکہ تاریخ کی معلومات غیر ضروری طور پر تبدیل نہ ہوں۔

### 🌐 عربی اور اردو کے لیے دائیں سے بائیں تحریر

Frontmatter Studio عربی اور اردو متن کو خودکار طور پر پہچانتا ہے اور ایسے متن کے لیے تحریر کی سمت **دائیں سے بائیں** کر دیتا ہے۔

اس کی وجہ سے اردو اور عربی مواد میں ترمیم کرنا زیادہ آسان اور قدرتی محسوس ہوتا ہے۔

### 🏷️ ٹیگز

ٹیگز کو کوما کے ذریعے الگ کرکے آسانی سے درج کریں۔

مثال:

```text
اسلام،مذہب،دین
```

عربی یا اردو کوما `،` کو خودکار طور پر عام کوما `,` میں تبدیل کیا جاتا ہے۔

ٹیگز Markdown فائل میں ایک ہی سطر میں YAML فہرست کی صورت میں محفوظ کیے جاتے ہیں:

```yaml
tags: ["اسلام", "مذہب", "دین"]
```

### 🖼️ تھمب نیل منتخب کریں

اپنے موجودہ ورک اسپیس سے تصویر منتخب کرنے کے لیے فائل منتخب کرنے کی سہولت استعمال کریں۔

منتخب کی گئی تصویر کا راستہ ورک اسپیس کے لحاظ سے محفوظ کیا جاتا ہے اور تصویر کا پیش منظر بھی دکھایا جاتا ہے۔

مثال:

```yaml
thumbnail: "images/example.jpg"
```

### ✅ Frontmatter کی جانچ

اپنی Markdown فائل کے Frontmatter کو محفوظ کرنے سے پہلے جانچیں۔

یہ سہولت غلط یا نامکمل Frontmatter کی نشاندہی کرنے میں مدد دیتی ہے۔

### 💾 تبدیلیاں محفوظ کریں

آپ کی تبدیلیاں اسی اصل Markdown فائل میں محفوظ کی جاتی ہیں جسے آپ نے کھولا تھا۔

اگر Markdown فائل کا ٹیب بند بھی کر دیا جائے تو Frontmatter Studio اس فائل کو یاد رکھتا ہے اور محفوظ کرتے وقت اسی فائل میں تبدیلیاں کرتا ہے۔

## 🚀 استعمال شروع کرنے کا طریقہ

1. Visual Studio Code میں کوئی Markdown (`.md`) فائل کھولیں۔

2. کمانڈ پیلیٹ کھولیں۔

   macOS پر:

   `Cmd + Shift + P`

   Windows اور Linux پر:

   `Ctrl + Shift + P`

3. درج ذیل کمانڈ چلائیں:

   **Frontmatter Studio: Open Editor**

4. بصری ایڈیٹر میں اپنی Frontmatter معلومات تبدیل کریں۔

5. اپنی تبدیلیاں محفوظ کریں۔

---

## 📋 مثال

مثال کے طور پر کسی Markdown فائل کا Frontmatter اس طرح ہو سکتا ہے:

```yaml
---
title: "میرا مضمون"
description: "یہ ایک مثال ہے"
author: "Generalsoft"
date: "2026-09-07"
thumbnail: "images/example.jpg"
tags: ["اسلام", "مذہب", "دین"]
---
```

Frontmatter Studio اس معلومات کو ایک آسان بصری فارم میں دکھاتا ہے تاکہ آپ کو YAML کی ساخت خود لکھنے کی ضرورت نہ پڑے۔

## 🛠️ دستیاب کمانڈز

Visual Studio Code کا کمانڈ پیلیٹ کھولیں اور **Frontmatter Studio** تلاش کریں۔

دستیاب کمانڈز:

* **Frontmatter Studio: Open Editor**

  * Frontmatter میں ترمیم کرنے کے لیے بصری ایڈیٹر کھولتا ہے۔

* **Frontmatter Studio: Validate Frontmatter**

  * موجودہ Markdown فائل کے Frontmatter کی جانچ کرتا ہے۔

## 🌍 اردو اور عربی مواد

Frontmatter Studio خاص طور پر ایسے Markdown مواد کے ساتھ بھی کام کر سکتا ہے جس میں اردو، عربی اور انگریزی ایک ساتھ استعمال ہو رہی ہوں۔

اردو اور عربی متن کو خودکار طور پر دائیں سے بائیں دکھایا جاتا ہے، جبکہ انگریزی متن کے لیے بائیں سے دائیں سمت استعمال کی جاتی ہے۔

مثال:

```yaml
---
title: "اسلام اور معاشرہ"
description: "ایک مختصر تعارف"
author: "Generalsoft"
tags: ["اسلام", "مذہب", "دین"]
---
```

## 🖼️ تھمب نیل کی تصاویر

جب آپ ورک اسپیس سے تھمب نیل منتخب کرتے ہیں تو Frontmatter Studio اس تصویر کا راستہ ورک اسپیس کے مطابق محفوظ کرتا ہے۔

مثال:


اس طریقے سے Markdown فائل اور اس کی تصاویر ایک ہی منصوبے کے اندر منظم رہتی ہیں۔
